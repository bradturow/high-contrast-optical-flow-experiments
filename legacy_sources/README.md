# Supporting legacy sources

These notebooks are preserved as exact migration sources rather than runnable
public notebooks:

- `exploring_the_sintel_dataset.ipynb` contains the contrast/directionality
  diagnostics and frame-labeling work used by manuscript figures.
- `step_edge_torus_pictures.ipynb` contains code for theoretical torus and
  step-edge-annulus diagrams.

Both use hard-coded paths and notebook-to-notebook `%run` dependencies. Their
useful code will be extracted into self-contained scripts or notebooks; these
copies should remain unchanged for provenance.
